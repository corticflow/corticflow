Padrão de Heartbeat e Gestão de Orçamento para Agentes Always-On

Com o surgimento de agentes autônomos contínuos (Persistent Mode), implemente ciclos rígidos de verificação orçamentária e poda periódica de memória episódica para evitar saturação do contexto em tarefas que duram dias. 

// Padrão de Isolamento e Segurança para Agentes Always-On
async function runPersistentAgentLoop(agentSession) {
  while (!agentSession.isInterrupted()) {
    // 1. Trava de segurança: teto orçamentário diário
    if (agentSession.getCumulativeCost() > DAILY_BUDGET_LIMIT) {
      await agentSession.sleepUntilNextBillingCycle();
      break;
    }
    // 2. Executa a próxima subtarefa com timeout estrito
    await agentSession.executeNextQueuedTask({ timeoutMs: 45000 });
    // 3. Compactação de memória para evitar drift de atenção
    await agentSession.pruneEpisodicMemory();
  }
}
