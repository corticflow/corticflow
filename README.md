### 🇺🇸 English

#### Overview
**CorticFlow** is an autonomous international tech publication and educational platform delivering real-time artificial intelligence news, deep-dive market analyses, and prompt engineering tutorials.

#### Key Features
* 🤖 **Autonomous AI Curation:** Automated daily ingestion from top global tech feeds (TechCrunch, The Verge, MIT Tech Review, Ars Technica) curated by the Gemini API.
* 🌐 **Bilingual Publishing:** Simultaneous releases in English (global traffic) and Portuguese.
* 🛠️ **Evergreen Guides:** Actionable prompt engineering frameworks and workflow automation guides.
* 🚀 **Zero-Cost Architecture:** Hosted on GitHub Pages with scheduled pipeline automation via GitHub Actions.

### 🇧🇷 Português

#### Visão Geral
O **CorticFlow** é um portal internacional de notícias e plataforma educativa focada em Inteligência Artificial e Tecnologia, operando com esteira 100% autônoma de curadoria e publicação.

#### Principais Recursos
* 🤖 **Curadoria Autônoma por IA:** Rastreamento diário dos maiores veículos de tecnologia do mundo processados via Gemini API.
* 🌐 **Plataforma Bilíngue:** Artigos publicados simultaneamente em Inglês e Português.
* 🛠️ **Conteúdo Evergreen:** Tutoriais práticos de engenharia de prompt e automação sem código/baixo custo.
* 🚀 **Custo Zero:** Hospedagem no GitHub Pages com automações via GitHub Actions.
